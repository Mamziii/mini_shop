# 🛍️ Mini Shop

A simple online shop built with **React, TypeScript, and Vite**.

## 🚀 Live Demo

[Watch live demo](https://mini-shop-kohl.vercel.app/)

## 📸 Screenshot

![Screenshot](./public/screen-2.jpeg)
![Screenshot](./public/screen-1.jpeg)


## ✨ Features

* 🛍️ Display products
* 🛒 Add products to cart
* ➕ Increase / decrease quantity
* 🗑️ Remove products from cart
* 💰 Calculate total price
* 📱 Responsive design

## 🛠️ Technologies

* React
* TypeScript
* Vite
* React Router
* React Query
* Axios
* Swiper
* React Hot Toast

## ⚙️ Installation

```bash
git clone https://github.com/Mamziii/mini_shop.git

cd mini_shop

npm install

npm run dev
```
